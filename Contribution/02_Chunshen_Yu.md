## 2. Main Difficulty and How It Was Resolved

The biggest difficulty was keeping the visual design consistent with the actual data. Some early candidate charts placed results from different training protocols, devices or thresholds side by side, which implied comparisons that the experiments do not support. Rather than merely restyling the slides, I required every plotted value to be traced back to a named result file and to one evaluation path before it was drawn. This meant rebuilding several charts from the original records instead of copying them between versions of the deck.

## 3. Reflection

Layout decides which results an audience treats as comparable. I revised the slides more often than was necessary early on, and the deck still needs a table-by-table check against the final report before the presentation. Keeping the offline version and the PDF aligned is an additional chore that is easy to postpone. In future work I would fix the presentation structure earlier and maintain one source of truth for every number, so that the slides cannot drift away from the report while the experiments are still changing.
