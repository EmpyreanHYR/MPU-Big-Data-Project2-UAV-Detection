## 汇报时怎么解释

PinP2有2,516,264个参数；原生AP50:95为31.274%，比匹配YOLO26n基准高3.322个百分点。当前H10＋NMS0.4的部署AP50:95为31.740%，三轮阈值基准22.89±0.01 FPS。原生AP取自训练后内部验证评价路径，部署AP取自H10＋固定NMS评价路径，两者并列报告。500图部署验收的单次22.56 FPS与三轮测速均值分别记录。

原跨模型对照表中，PinP2采用无NMS路径，最终选型综合精度、漏检、大小与速度；YOLO11n的H10 AP更高、YOLOv8n漏检更低。[选型说明](results/FINAL_SELECTION_PCONV_P2_20261104.md)保留这一取舍。PinP2 NMS0.4结果单列，其余模型在该表中按未加NMS路径评价。

实验使用seed42；P2组物理batch8，其余YOLO26主消融batch32。模型和NMS阈值在内部验证集上选定，跨域表现仍偏低，密集目标、独立连续视频与长期摄像头运行未覆盖。11月3日三段旧演示属于SIA＋CSP；11月16日GUI使用最终PinP2，素材为图像循环。详细口径见[复现说明](report/REPRODUCIBILITY_NOTES.md)。

课程关联：veracity对应重复、冲突及标注尺度审查；volume对应三档训练量和推理负载；velocity对应H10吞吐及实际窗口绘制。VLM复核为已完成的LLM相关实验，结果支持维持纯阈值过滤，VLM未进入H10部署路径。
