# 当前项目状态

2026-10-23：YOLO26n 三种结构、SIRST-UAVB 处理流程及英文提案已完成本轮代码与文档检查。后续开发以本仓库为准。

## 已完成

B0 baseline、B1 浅层 PConv、B2 stride4 P2 分支均有模型配置、统一构建适配器和独立实验配置。自定义训练器从 YAML 重建 PConv；检查点恢复和公共前缀权重迁移已经测试。三种模型均保留端到端预测。结构及初始化策略见 [模型说明](../configs/models/README.md)。

数据处理支持原生 YOLO/VOC 框、显式类别映射、UAV 单类标签和鸟框保留、来源组划分、文件/像素重复检测、坐标校验及独立输出审计。操作见 [PREPARATION.md](datasets/PREPARATION.md)。合成数据测试通过，实际 SIRST-UAVB 下载包尚未取得，其类别 ID、来源组和正式划分尚待核验。

英文提案已翻译并写入 `docs/proposal/main.tex` 与 `body_en.tex`，中文原稿保留为 `main_zh.tex` 和 `body_zh.tex`。13条文献使用 BibTeX 自动编号，双语引用顺序一致。英文 PDF 三页编译成功并逐页视觉检查。原 IEEE ZIP、六个成员、宏包、类、示例作者、thanks 和页眉通过保护检查。报告仍为章节框架，PPT仍为大纲。

## 本轮验证

23项测试通过：模型5项、数据12项、训练运行条件6项。模型验证为 CPU 随机权重前向（含640×640和非方形输入）、结构恢复及临时合成检查点读写；无 loss/backward/optimizer 或训练循环。三种模型输出为 `[1,300,6]`，B0/B1 步长8/16/32，B2步长4/8/16/32，数值均有限。详情见 [模型检查记录](checks/model_smoke_20261023.json)及 [REPOSITORY_CHECKS.json](REPOSITORY_CHECKS.json)。

本轮没有训练、开启云实例、下载实际数据/预训练权重、实测 GPU 或进行 H10 部署。训练计划中的300轮尚未执行；当前没有新数据集检测精度或改进收益。Mac/Pi禁训限制保持，云端原累计预算和截止不重置。
