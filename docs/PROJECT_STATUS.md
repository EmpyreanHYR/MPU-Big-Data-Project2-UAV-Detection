## 汇报时怎么解释

PinP2有2,516,264个参数；原生AP50:95为31.274%，比匹配YOLO26n基准高3.322个百分点。当前H10＋NMS0.4的部署AP50:95为31.740%，三轮阈值基准22.89±0.01 FPS。两种AP来自不同评价路径，不能直接当作同一指标的前后提升。500图部署验收的单次22.56 FPS也不混入三轮测速均值。

最终模型综合考虑精度、漏检、大小与速度；YOLO11n的H10 AP更高、YOLOv8n漏检更低。[选型说明](results/FINAL_SELECTION_PCONV_P2_20261104.md)保留这一取舍。

实验只有seed42；P2组物理batch8，其余YOLO26主消融batch32。模型和NMS阈值复用了内部验证集，跨域表现仍偏低，密集目标、独立视频与长期摄像头运行没有得到验证。三段已有演示属于SIA＋CSP，不能标成最终PinP2模型视频实测。详细口径见[复现说明](report/REPRODUCIBILITY_NOTES.md)。
