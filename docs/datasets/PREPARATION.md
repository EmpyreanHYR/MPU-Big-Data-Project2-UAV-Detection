# 当前数据处理流程

SIRST-UAVB原始3000张图像经可读性、标签配对、类别和坐标检查，排除494张像素重复图像、隔离7张标注冲突图像，保留2499张。使用seed42和推断背景视图分组，固定1999训练／500验证；训练与验证分别包含1980／486个UAV框、20／15张无UAV负样本。

1. 保留原始下载包、图像与原标注；处理结果另存，不覆盖原件。
2. UAV框映射为单类；鸟类不作为正例，保留其原始信息用于错误归因。
3. 固定图像和标签清单，保存来源与SHA256，检查训练／验证的组和像素重复。
4. 所有有效模型使用相同1999／500清单；输入640，保持宽高比并填充。
5. 四个外部来源分别转换与评价，标明原生框和由分割派生的框。外部数据不参与当前训练或选点。
6. H10校准只使用训练图像，禁用梯度微调；提供1024张训练图，日志核验实际统计64张。各模型数量和哈希以其编译回执为准。

没有独立SIRST测试集，原始视频／会话编号未发布；不能将推断背景分组表述为已验证的视频级隔离。[来源及规模](SOURCES.md)、[单源协议](../experiments/SIRST_CROSSDATA_20261102.md)和[当前结果](../results/EXPERIMENT_TABLES_20261105.md)共同说明本轮实际采用的组成。
