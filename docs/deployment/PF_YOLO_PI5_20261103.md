# YOLO26＋SIA＋CSP树莓派5实测

本轮从原YOLO26、SIA、SIA＋CSP三种从零100轮模型中，按内部验证mAP50–95选择SIA＋CSP。其最佳轮次96，mAP50为66.911%、mAP50–95为28.583%；相同条件的原YOLO26为65.760%／27.952%。完整指标及Recall下降情况见[训练对比](../results/PF_YOLO100_20261103.md)。

## 导出与功能验证

采用固定单张640×640的ONNX模型，RGB居中letterbox、114填充、双线性缩放、除255归一化；置信度阈值0.25，沿用端到端输出，不增加额外NMS。模型SHA256为`d9be52b9d66b1ae09a229b4af0a5cbba9e4ea57c2065d73fda000bfb377708bf`。

为保留输入自适应的尺度路由，导出适配器计算各专家，再以张量TopK和Scatter权重选择，而不把Python条件判断在示例输入上的结果固化。所有学习参数不变，覆盖三种top2尺度选择的检查通过。8张固定内部验证图像在云端的8400位置原始框／分类分支数值一致性检查，以及阈值0.25的最终检测集合检查通过。低置信度候选的并列TopK顺序可不同，不声称最终候选矩阵逐行相同。

通过Tailscale连接树莓派5，保留已有目录及服务，使用桌面mpu-class下的独立部署目录与虚拟环境。Pi端文件哈希校验通过，8张样例均实际推理，检测数量与云端参考相同，保存检测可视化、JSON、运行日志及依赖锁定文件。样例验证不是新独立数据集评测，也未重新计算整个验证集的部署后mAP。
