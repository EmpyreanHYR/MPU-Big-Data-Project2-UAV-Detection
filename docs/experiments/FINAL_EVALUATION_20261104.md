# 结项统一评测与选型

训练结束后综合所有评价指标选择结项模型，并补齐已完成模型的GPU与树莓派推理、漏检校验，用draw.io绘制最终模型网络图。全15模型GPU与Pi实测完成，当时选择原YOLO26n的COCO预训练150轮权重；随后的树莓派＋H10评测把最终选择定为YOLO26n＋PConv＋P2；见[当前选型依据](../results/FINAL_SELECTION_PCONV_P2_20261104.md)和[完整对比](../results/COMPLETE_MODEL_TABLE_20261104.md)。

## 一致的检测口径

使用冻结SIRST内部验证500张／486个UAV框，640×640、FP32、batch1、同一RGB双线性居中letterbox114预处理。部署置信度固定0.25，NMS IoU0.7，max_det300。以IoU≥0.5一对一匹配计算TP、FP、FN，漏检率为FN／(TP＋FN)，同时记录固定阈值P/R/F1、FP／图和负样本图误报。原训练报告的最大F1工作点Recall单独保留，与这里的漏检率是两种口径。

各模型原生内部验证mAP50、mAP50–95保留；共同部署流程另以score下限0.001和十个IoU阈值计算部署AP，两个评价流程并列报告。四源外部结果补充同协议GPU外部评价。GPU和Pi均在相同500张图上实际推理；Pi使用ONNX Runtime CPU，H10加速成绩由[H10扩展评测](../results/EDGE_EXTENSION_20261104.md)单独列出。

## 时延与转换

GPU使用CUDA同步，Pi使用CPU session.run计时，均先预热20次，再记录全500张图像的每次时延。分别报告纯推理、含读图／预处理／传输／后处理／坐标还原的管线mean、p50、p95和FPS，另外记录总评测墙钟时间、显存或RSS、模型大小与模型哈希。图像管线不含绘图、视频编码、网络，属于图像级吞吐指标。

导出和模型加载在云端执行。逐模型记录Torch／ONNX多样输入检查；PF两个版本保留输入相关top-k尺度路由，并覆盖三种路由组合。导出失败、数值校验失败、Pi推理失败均单列记录并逐项处理。GPU与Pi逐图预测和漏检数回传后复核。

## 选型与结构图

先筛选通过导出验证和实际Pi全500图推理的候选，展示共同部署精度（GPU/Pi中较低的AP95，高）、漏检率（两端中较高值，低）、Pi／GPU管线p95延迟（低）和模型大小（低）的Pareto取舍。课程项目默认精度优先：按共同部署AP95、较高漏检率、Pi p95、GPU p95、模型大小的顺序作进一步取舍；原训练AP独立保留用于训练实验分析。COCO预训练150轮、从零100轮、从零150轮保持标识，不同训练条件的优胜按条件分别解释。

用所选实际权重的配置、层连接和张量形状制作draw.io可编辑网络图，导出SVG/PNG，图中只画实际使用的结构。报告和PPT引用该图。
