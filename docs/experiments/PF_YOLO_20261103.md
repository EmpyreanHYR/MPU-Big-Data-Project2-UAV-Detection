# 将PF-RPN的视觉自提示迁移到YOLO26

依据：Tang等《Prompt-Free Universal Region Proposal Network》，CVPR2026，用户提供的论文与作者PF-RPN代码。主要对应论文第3.2、3.3节公式1–3，以及作者`PFRPN._build_sparse_moe_pseudo_text`、`cascade_self_prompt_enhancement`。作者入口：[PF-RPN](https://github.com/tangqh03/PF-RPN)。

目标是在现有SIRST-UAVB无人机单类检测中，试验图像自适应的尺度选择和前景特征聚合。新增版本称为“PF-RPN启发的YOLO26”，属于方法迁移，不是完整PF-RPN复现，也不代表已具备论文的零样本通用目标提议能力。普通YOLO本来就不需要文本提示，新增价值在于视觉自提示与多尺度选择。

## 接入位置与版本

`YOLO26骨干及原有颈部 → P3/P4/P5 → SIA → 可选CSP → 残差相似度门控 → 原YOLO26检测头`

| 版本 | SIA | CSP | 用途 |
|---|---|---|---|
| baseline | 无 | 无 | 已有从零100轮参照 |
| pf_sia | top2尺度路由与跨注意力 | 无 | 单模块消融 |
| pf_sia_csp | top2尺度路由与跨注意力 | 深到浅3次 | 组合改进 |

SIA先把三层特征投影到32维，按图像全局特征为每层打分。每幅图选择两层，以一个可学习视觉token为query，以所选层全局与局部特征为key/value做跨注意力，再按路由权重汇总。保持完整空间位置，不先裁去小目标。

CSP用当前token与各位置特征的余弦相似度生成掩码，阈值0.3；按P5→P4→P3更新token，共3次。没有位置超过阈值时补充量为零，避免空掩码除零。它不读取标注，也不读取其他图像或其他batch的token。

YOLO没有原论文的文本对齐编码器，因此新增一个桥接方式：用最终token与各尺度特征的余弦相似度调制原特征，形式为`x * (1 + tanh(gain) * similarity)`，gain初值0.1。保持各层通道数、分辨率、预测位置及原有检测分支。门控是本项目的适配设计，不是论文公式。

路由平衡项为`0.01 * std(softmax(router_logits))`，按每图尺度概率计算再取batch均值；这是对论文路由平衡思路的明确实现选择。训练总目标为原检测损失加该项，日志单独记录`router_loss`。不向原框损失列混入辅助损失。

## 与原论文的边界

原论文基于Grounding DINO/Swin-B，包含多层Transformer适配、视觉文本增强、CG-QS、centerness监督及COCO/ImageNet联合数据。本实现使用一个32维token、共享单层跨注意力与轻量YOLO门控。保留YOLO26原有端到端one-to-many/one-to-one分支、匹配器和框损失，不加入CG-QS与centerness。YOLO的稠密预测位置和DETR的decoder查询不同，不能把一个未监督的中心分数直接乘上检测置信度就称为CG-QS复现。
