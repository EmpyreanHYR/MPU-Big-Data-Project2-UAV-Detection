# 将PF-RPN的视觉自提示迁移到YOLO26

依据：Tang等《Prompt-Free Universal Region Proposal Network》，CVPR2026，用户提供的论文与作者PF-RPN代码。主要对应论文第3.2、3.3节公式1–3，以及作者`PFRPN._build_sparse_moe_pseudo_text`、`cascade_self_prompt_enhancement`。作者入口：[PF-RPN](https://github.com/tangqh03/PF-RPN)。

目标是在现有SIRST-UAVB无人机单类检测中，验证图像自适应的尺度选择和前景特征聚合。新增版本称为“PF-RPN启发的YOLO26”，属于方法迁移；新增价值在于视觉自提示与多尺度选择。

## 接入位置与版本

`YOLO26骨干及原有颈部 → P3/P4/P5 → SIA → 可选CSP → 残差相似度门控 → 原YOLO26检测头`

| 版本 | SIA | CSP | 用途 |
|---|---|---|---|
| baseline | 无 | 无 | 已有从零100轮参照 |
| pf_sia | top2尺度路由与跨注意力 | 无 | 单模块消融 |
| pf_sia_csp | top2尺度路由与跨注意力 | 深到浅3次 | 组合改进 |

SIA先把三层特征投影到32维，按图像全局特征为每层打分。每幅图选择两层，以一个可学习视觉token为query，以所选层全局与局部特征为key/value做跨注意力，再按路由权重汇总。特征保持完整空间位置，小目标以原分辨率参与。

CSP用当前token与各位置特征的余弦相似度生成掩码，阈值0.3；按P5→P4→P3更新token，共3次。没有位置超过阈值时补充量为零，避免空掩码除零。它只读取当前图像的特征，不使用标注或其他图像的token。

YOLO没有原论文的文本对齐编码器，因此新增一个桥接方式：用最终token与各尺度特征的余弦相似度调制原特征，形式为`x * (1 + tanh(gain) * similarity)`，gain初值0.1。各层通道数、分辨率、预测位置及原有检测分支保持不变。门控是本项目的适配设计。

路由平衡项为`0.01 * std(softmax(router_logits))`，按每图尺度概率计算再取batch均值，是本项目对论文路由平衡思路的具体实现。训练总目标为原检测损失加该项，日志单独记录`router_loss`。

## 与原论文的边界

原论文基于Grounding DINO/Swin-B，包含多层Transformer适配、视觉文本增强、CG-QS、centerness监督及COCO/ImageNet联合数据。本实现使用一个32维token、共享单层跨注意力与轻量YOLO门控。检测沿用YOLO26原有端到端one-to-many/one-to-one分支、匹配器和框损失，未加入CG-QS与centerness。YOLO的稠密预测位置和DETR的decoder查询结构不同，因此中心分数与置信度的组合方式按本项目设计。

2026-11-03云端CPU合成检查通过：两种结构的正方形／矩形前向与端到端输出、四项损失记录及路由／投影／token／门控梯度、空掩码稳定性与逐图独立性、零门控恒等映射、训练器从YAML重建与原生验证器构造、检查点保存恢复和EMA所需深复制。共3个测试方法，6.710秒。输入为随机合成数据；训练器重建日志的“pretrained weights”指同一合成模型内存参数的复制。

## 正式训练（2026-11-03）

两个版本各100轮并与原YOLO26比较。接续控制器等待RT-DETR和MSF两组完成100轮并释放串行锁，顺序为SIA100→SIA＋CSP100。等待最长48小时，每组正式训练最长48小时；前置队列失败时接续停止，GPU 由当前运行作业独占。

每个版本在正式训练前完成了原生CPU一轮合成训练检查，覆盖训练、验证、四项损失CSV、EMA及best/last保存；合成精度不作为正式结果。640／batch32／FP32的GPU前后向与AdamW显存检查在前置队列完成后运行，两组均通过后开始正式训练。

对照为原YOLO26从零100轮，其最佳验证轮次为100，mAP50=65.760%、mAP50–95=27.952%。两份新配置与原基准的实际初始化记录逐字段一致：数据清单、100轮、640、seed42、batch32、nbs32、FP32、无预训练、AdamW和学习率。基准CSV及最佳权重哈希已登记，本组直接引用该基准。

两组完成后生成`comparison.json`和`comparison.md`，列出Precision、Recall、F1、mAP50、mAP50–95及相对基准的AP95百分点变化。所有指标取各自验证AP95最佳的同一CSV行，模型选择只用内部验证。COCO预训练150轮成绩作为独立初始化组并列。

2026-11-03晚间：两个版本均完成100轮并通过CSV／完成标记／权重哈希检查；对比见[100轮结果](../results/PF_YOLO100_20261103.md)。

2026-11-03晚间：所选SIA＋CSP完成树莓派5 CPU部署、8张样例推理与回传文件哈希校验，详见[部署实测](../deployment/PF_YOLO_PI5_20261103.md)。
