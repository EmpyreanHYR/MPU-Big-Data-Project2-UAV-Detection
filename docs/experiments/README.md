# 实验导航

当前主范围为11个从零100轮模型，使用同一1999／500划分。累计19组完成记录还包含4组COCO初始化150轮、2组早期从零150轮和2组训练比例权重；各组单独标识。

- [单源与跨数据集协议](SIRST_CROSSDATA_20261102.md)：数据组成、选点及外部评价。
- [PConv／P2补充消融](SIRST_SCRATCH_ABLATIONS_20261104.md)：三组新增100轮结构实验，与既有从零基准比较。
- [PF启发适配](PF_YOLO_20261103.md)：SIA及SIA＋CSP的迁移范围。
- [比较模型与初始化](SIRST_COMPARISONS_20261102.md)及[适配器来源](COMPARISON_ADAPTERS_20261031.md)：各模型家族的训练设置。
- [统一部署评价协议](FINAL_EVALUATION_20261104.md)：固定阈值匹配、独立AP和硬件计时。
- [当前结果导航](../results/README.md)：最新四类表格、设备比较与规模／错误分析。

数据比例25%／50%／100%分别表示500／1000／1999张训练图，共用500张验证。100%沿用已完成实验，25%与50%已各完成100轮及GPU500评价，见[训练比例实测](../results/TRAINING_FRACTIONS_20261107.md)。两个比例权重已完成GPU评价，Pi/H10评价为主要模型的补充测项。125／250／500张H10补测是推理工作负载，与训练数据比例相互独立。

各协议文档按日期保留当时的状态描述与选型过程。当前最终模型是PinP2-YOLO（YOLO26n＋PConv＋P2），数量和结果以上述结果导航为准。
