# SIRST-UAVB 单源改进模型实验

2026-11-02：补齐当前单源数据上的改进模型训练，实例已开机。串行运行 PConv、P2、PConv＋P2，每组150轮，启动和完成状态以实际云端记录为准。

沿用冻结的 SIRST-UAVB 1999 train／500 val，seed42、640输入、FP32、AdamW、nbs32；PConv物理batch32，含P2的两组物理batch8。其余四个来源作为分别报告的外部测试，选权重只用内部验证。每组从原始官方COCO权重重新初始化，训练从第1轮开始。

初始化采用已有适配器的公共图前缀0–16层同名同形迁移；PConv层1和分叉后路径为随机初始化。训练器重建后核对已迁移张量与PConv/P2结构。现有单源基准加载全部兼容张量，本轮改进模型只加载公共前缀，因此两者的初始化范围不同（342／348／342个迁移张量对比基准的完整兼容加载），结构分数按各自初始化范围解释。物理batch差异同样保留。

三组正式训练前分别运行云端固定batch、640、FP32的合成前向／反向及优化器分配检查；合成检查不计入正式轮次，不产生检测精度。同时验证原始官方权重、导出清单及逐图哈希、来源组跨角色隔离，并确认单源基准150轮完成。

队列持有已有两把串行锁，每个GPU作业为独立新会话子进程，预检最多15分钟、正式单组最多48小时。某组失败时队列在该组停止并记录状态，其余计划以新的显式授权继续。

配置：[PConv](../../configs/experiments/sirst_only150/pconv.json)、[P2](../../configs/experiments/sirst_only150/p2.json)、[组合](../../configs/experiments/sirst_only150/pconv_p2.json)。
