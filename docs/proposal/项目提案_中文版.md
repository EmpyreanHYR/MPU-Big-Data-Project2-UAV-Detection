# 基于改进 YOLO26 的红外小目标无人机检测研究

**《大数据概论》小组项目提案 · 中文版 V4.0**  
小组成员：黄耀荣、余春申、翟逸凡、罗智文  
日期：2026年10月23日

## 摘要

针对复杂背景下红外无人机目标尺寸小、对比度低和背景干扰强的问题，本项目采用 YOLO26n 目标检测框架，研究浅层特征提取与高分辨率预测对微小目标检出的影响。以 SIRST-UAVB 为主数据集，结合通用红外小目标数据开展对照实验，考察 PConv 卷积和 P2 检测分支的作用。项目从检测精度、漏检误报和端到端延迟三个方面评价模型，并在树莓派与 H10 平台开展视频推理验证，形成数据处理流程、检测模型、实验分析与课程汇报材料。

## 研究背景与文献分析

红外无人机目标通常只占据少量像素，其弱纹理和低对比度使特征提取、定位与背景区分紧密相关。YOLO26 采用双头训练结构，支持端到端预测，并通过去除 DFL、引入渐进式损失和小目标感知标签分配 STAL，改善检测头效率与微小目标的正样本覆盖。本项目选用 YOLO26n，在其特征提取与预测分辨率两个环节开展研究[1, 2]。

在局部特征建模方面，Yang 等提出的 PConv 通过风车形方向采样扩大浅层感受野，并依据红外目标的空间分布增强特征表达[3]。EFLNet 则从目标背景不平衡、微小框回归敏感性和多层特征利用出发，结合自适应损失、NWD 与动态检测头改善红外框检测[4]。这些研究说明，浅层采样方式和跨尺度信息利用是红外检测中值得关注的环节，也为本项目选择局部卷积替换提供了依据。

对于检测分辨率与计算效率，TY-RIST 在 YOLO 框架中结合高分辨率检测头、细粒度特征和分支裁剪，分析了微弱目标检出与计算开销之间的关系[5]。RDANet 从结构退化角度研究下采样损失，DNANet、ISNet 和 ACM 分别通过密集特征交互、形状边缘建模和上下文调制保留弱目标信息[6, 7, 8, 9]。本项目据此将 P2 高分辨率预测分支作为另一候选，比较特征分辨率变化对召回率和推理延迟的影响。

微小目标的框定位还受到像素偏移的影响。Wang 等将目标框表示为高斯分布，以归一化 Wasserstein 距离衡量相似性，为小框回归提供了更平滑的几何度量[10]。本项目首先研究卷积和预测分支，随后结合定位误差分析，评估这类几何度量用于回归损失的研究价值。

## 项目目标

项目围绕复杂背景中的红外无人机框检测，建立数据整理、模型训练、指标评价和视频推理流程。研究重点是比较浅层卷积调整与高分辨率预测对微小目标的影响，并结合目标尺度、背景类型和推理开销确定最终模型。主要成果包括模型代码、训练记录、对比与消融结果、树莓派视频演示，以及课程报告和汇报 PPT。

## 数据集与处理流程

主实验采用 SIRST-UAVB。该数据集包含 3000 幅真实红外图像，提供 2955 个无人机框和 1742 个鸟类框[3]。项目以无人机为检测类别，利用鸟类标注分析相似飞行目标造成的误报。图像统一进行尺寸、框坐标和类别映射检查，建立固定训练、验证与测试清单。

补充实验采用 IRSTD-1k 的 1001 幅真实图像、NUDT-SIRST 的 1327 幅合成图像，以及 SIRST 的 427 幅真实图像[7, 8, 9]。这些实验分别设置通用红外目标类别，优先使用匹配的框标注；像素标注按目标连通域生成外接框，并对粘连目标和极小框进行抽查。数据处理保留来源、尺寸及标注转换记录。

扩展数据包括具有复杂背景和框标注的 SIRST-V2、包含密集目标与背景语义的 DenseSIRST，以及面向海面舰船的 NUDT-SIRST-Sea[11, 12, 13]。数据划分按来源序列或原始大图组织，跨版本和跨数据集样本统一进行重复检查；SIRST-V2 与 SIRST 的包含关系纳入清单管理。

## 技术路线与算法设计

技术路线为数据准备、YOLO26n 基线训练、候选模块比较、模型选择、视频验证与边缘部署。模型输入设为 640×640，采用保持宽高比的预处理，输出无人机框及置信度。

基线 B0 采用 YOLO26n，沿用其检测头、损失和标签分配机制[1, 2]。方案 B1 在浅层选择一处标准卷积进行 PConv 替换，研究局部感受野与方向采样的作用[3]。方案 B2 在 YOLO26n 特征金字塔中新增步长为 4 的 P2 预测分支，与原 P3、P4、P5 分支共同进行检测，研究更高空间分辨率的作用。

B1 和 B2 分别与 B0 对比，依据验证集精度、微小目标召回和计算开销选择主要方案。消融实验进一步比较模块位置及组合配置，分析各部分对最终结果的贡献。

## 实验设计与评价

训练采用云端 GPU，以相同来源的 COCO 预训练权重初始化，计划训练 300 轮。各组采用一致的数据划分、输入尺寸、增强策略和模型选择规则，记录新增层的初始化方式。以验证集 mAP@0.5:0.95 选择模型，再开展测试集评价，并通过配对随机种子考察主要结论的稳定性。

检测效果采用 Precision、Recall、F1、mAP@0.5 和 mAP@0.5:0.95 评价。按原图中的目标尺寸及背景复杂程度分组，分析弱目标漏检、鸟类误报和小框定位偏差。在验证集确定置信度与匹配阈值，统计每幅图的未匹配检测框数。

推理评价统一使用 YOLO26 的端到端预测分支与相同输出筛选设置，记录模型调用延迟、端到端 FPS、p50/p95 帧延迟和峰值内存。完整处理时间覆盖视频解码、预处理、推理、坐标还原与结果显示。

## 视频验证与边缘部署

选用独立的真实红外无人机视频，按来源划分验证序列，并对代表帧和连续片段进行标注。测试覆盖远距离目标、鸟类干扰、背景亮点和目标进出画面的场景，结合定量指标与检测叠加视频展示结果。

部署采用树莓派与 H10 加速平台，按浮点模型、ONNX 导出、量化校准、模型编译和视频推理逐步验证。校准样本从训练数据中选取，记录运行时、编译器和固件版本，比较浮点模型与部署模型的检测效果及端到端速度。

## 进度安排与预期成果

第一周完成文献与数据整理，固定训练和评价流程；第二周开展 YOLO26n 基线训练并实现候选模块；第三周完成主要对照、消融与补充数据实验，整理检测效果和效率结果；第四周完成视频验证、报告、PPT 和答辩彩排。

预期形成基于 YOLO26 的红外无人机检测模型、完整的数据与实验流程，以及面向树莓派 H10 的视频推理方案。研究结论将说明浅层采样和高分辨率预测在不同目标尺度、背景条件与计算资源下的作用。
