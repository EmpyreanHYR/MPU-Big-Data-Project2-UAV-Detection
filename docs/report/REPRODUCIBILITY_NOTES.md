# 评价口径与复现材料

本文档配合[正式报告](report.pdf)与[中文对应稿](report_zh.md)，记录评价口径、材料索引、NMS后处理实测与GUI证据。

资料更新于2026年11月16日。

## 原生与共同部署评价

| 项目 | 原生验证 | 共同FP32及H10评价 |
|---|---|---|
| 权重 | 各训练器最佳内部AP50:95检查点 | 同一冻结权重导出，H10再作训练集统计校准 |
| 输入及后处理 | 对应模型族验证器设置 | RGB转三通道、保持比例、Pillow双线性缩放及114填充到640×640；FP32输入除以255；H10使用UINT8输入 |
| P／R／F1工作点 | YOLO26原生评价器在1000点置信度曲线上取平滑平均F1的最大点；表内F1由所记P／R计算。其他模型保留各自原生记录 | 先按conf≥0.25筛预测，再以IoU≥0.5作一对一匹配；漏检为FN／486 |
| AP | 原生验证器记录 | conf下限0.001；IoU 0.50至0.95，每步0.05；101点精度包络梯形积分 |
| 输出分支 | 对应原生检测头 | YOLO26保留一对一输出；v8/v5式头解码后NMS IoU0.7、maxdet300；RT保留其查询输出 |
| 评分对象 | 同500张内部验证图，也用于选检查点 | 相同500图、486个UAV框，由保存预测及原GT重算 |

PinP2-YOLO的原生AP50:95为31.274%，共同FP32为25.186%，H10为24.351%。前两者相差6.088个百分点，来自预处理、候选生成和评分口径的综合影响；从共同FP32到H10的0.835个百分点为本次硬件转换路径的精度变化。

已有ONNX检查使用opset17及ONNX Runtime 1.20.1 CPU。YOLO26一对一原始分支容差为绝对1e-3、相对1e-4；conf0.25检测集合要求匹配。下表原始误差取八图及输出张量的最大绝对值。

| 冻结模型记录 | 检查图数 | 原始分支最大绝对误差 | conf0.25集合一致 |
|---|---:|---:|---:|
| scratch__yolo26n_scratch | 8 | 7.4386597e-05 | 8/8 |
| scratch100__pconv_p2 | 8 | 9.4413757e-05 | 8/8 |
| scratch__rtdetr_l | 8 | 6.9439411e-06 | 8/8 |

RT检查先对300个唯一查询作一对一位置对齐，再应用同一容差；YOLO26低分TopK排序可能不同，因此同时保留原始一对一分支和阈值集合检查。检查图索引为固定清单中的0、1、2、3、149、249、349、499。

## 所选权重的外部迁移评价

外部迁移只在AUVD-Seg300上进行。所选scratch100 PinP2-YOLO权重的原生AP50:95为11.494%，内部原生值为31.274%，差距反映跨域迁移的难度；它不是NMS0.4/H10策略的外部验证。外部数据未用于选权重或阈值。

## 2026-11-15：NMS与视觉语言复核

[后处理审计](../results/NMS_VLM_AUDIT_20261115.md)给出完整扫描及分析。YOLO26原e2e路径无NMS，元数据IoU0.7并未启用。离线NMS阶段重放既有预测，在原坐标裁剪后应用，固定分数及300上限。独立标量实现7000例一致；默认0.4下H10 AP31.740%、FP62、TP323／FN163。原跨模型表保留原无NMS精度和22.72 FPS，新变体速度以24次运行单独列示。

FP32在同一批预测中同样出现重复／匹配冲突。NMS重放改善的是部署后处理，原生AP31.274%与32.074%的FP32 NMS0.4 AP来自不同评价路径，分别报告。

视觉语言复核E0–E4已完成，保留为当前策略无优势的对照结果。E3同召回下FP12，纯阈值FP11。689次输出无UNCERTAIN；清晰语义正例与数值对照列入后续工作。原始响应、环境、裁剪及SHA证据保存在私有归档。

Pi5／H10共完成24次运行；原始预测逐图一致，指标独立复算及文件哈希核验通过。

最终默认采用NMS IoU0.4（conf0.25、max300）：H10 TP323／FP62／FN163、AP50:95 31.740%。三轮阈值基准为22.89±0.01 FPS、43.70±0.02毫秒／图，NMS26.3±0.1微秒／图；无NMS对照22.86±0.02 FPS。选择0.4因为它是召回不变且FP最低的测试阈值中较大的一档；0.3仅多0.0026个百分点AP，0.5多1个FP。

新的PinP2/H10部署入口在原图坐标还原及裁剪后调用NMS，绑定权重与HEF身份。500图默认策略验收未传入阈值覆盖，实际调用500次，442→385个候选（抑制57框），低分AP候选6969→4368；框、分数、顺序与冻结重放逐一相同。验收单次22.56 FPS／44.33毫秒，单列且不并入三次重复的阈值基准。所选阈值与模型复用同一500图验证集，属于内部工程选择；数据集仅1张双UAV图，密集目标行为由后续工作覆盖。

[部署代码与用法](../../scripts/deployment/README.md)及[验收汇总](../results/NMS_DEPLOYMENT_ACCEPTANCE_20261115.json)记录执行证据。
