## 最新演示、发布和失败分析

- [Release gui-h10-v1.0.0](https://github.com/EmpyreanHYR/MPU-Big-Data-Project2-UAV-Detection/releases/tag/gui-h10-v1.0.0)提供最终GUI HEF、匹配元数据、1080p成片、720p预览、双语字幕及校验和。真实推理按[GUI复现指南](../GUI_REPRODUCIBILITY.md)准备Pi5/HAILO10H和运行时；其他训练与原始实验资产仍未公开。
- [时间文字审计](../results/TIMESTAMP_AUDIT_20261116.md)：在原GT、conf0.25、IoU0.5下，30个源帧H10为TP0/FP18/FN30，过滤后为TP0/FP8/FN30；内部500图指标不变。706帧循环处理不能当作706个独立样本。
- [定位诊断](../results/LOCALIZATION_DIAGNOSIS_20261116.md)：同30图FP32/H10均为TP0，内部8图控制均为TP6。未发现GUI或坐标还原错误；标注范围、预测尺度与领域差异的贡献尚未完全分离。
- [速度](../results/GUI_NATIVE_20261116.md)按范围分开：NMS阈值基准22.89±0.01 FPS；未录屏真实桌面16.51 FPS；配音录屏活动绘制约10.57 FPS。成片25 FPS是采样率。
- VLM当前策略未优于同召回置信度过滤，已有结果继续保留；清晰UAV/鸟/背景对照及数值控制尚未做，扩大实验暂停。Pi/H10坐标检查不替代VLM输入或数值控制。
