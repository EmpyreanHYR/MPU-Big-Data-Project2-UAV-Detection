# 全部模型推理与跨数据集对比

全部12个已完成的SIRST单源模型均参与本轮补测；Faster R-CNN仍取消。检查点只按各自内部验证mAP50–95选择，外部结果不改变部署选择。四个COCO预训练150轮配置与八个从零初始化模型分组解读，其中YOLO11n／YOLOv8n150轮，其余从零模型100轮。不同模型家族及轮数的比较用于本项目实际效果观察。

效率统一在同一张RTX 2080 Ti、640×640、batch1、FP32、4个CPU线程上运行；8张固定图像相同。纯前向先预热20次，再循环200次，CUDA同步计时，使用未融合模型，包含各自原生检测头解码，但不含前处理、传输及模型后NMS。因此纯前向FPS不是最终检测吞吐。另以20次预热、80次计时测完整图像检测管线：JPEG读入、统一PIL双线性RGB letterbox114、归一化、H2D、原生模型、对应的NMS或端到端过滤、D2H及原图坐标还原；排除初始化、绘图、视频编码、网络和显示。阈值0.25、NMS IoU0.7、max_det300。RT-DETR的效率输入也使用该统一letterbox，外部精度使用其原生验证器预处理。

外部精度均采用split=test、640、FP32、confidence下限0.001、IoU参数0.7、max_det300；RT-DETR验证batch4，其余batch16，速度比较使用独立batch1测试。MSF使用固定作者YOLOv5验证器，其余使用固定Ultralytics验证器。P/R为各原生PR曲线的最大F1汇总点，F1由同组P/R计算；仅作结果描述，不把外部工作点用于调参或部署。三种已测模型的12条外部结果在确认权重哈希相同时沿用，其余36条新评测完成。
