# PinP2-YOLO最终平台三档规模与错误分析（2026-11-05）

最终模型和阈值固定，运行平台为树莓派5＋HAILO10H。125／250／500张为seed42嵌套子集，每档3次，三轮分别按125→250→500、250→500→125、500→125→250顺序执行，每次新进程、预热20次，共2625次计时推理。所有预测与此前同一HEF的500图输出完全一致。

尺寸按原始像素框面积的平方根d定义；尺寸分组统计目标，误报没有真实目标尺寸，因此对应FP为空。背景和鸟类组按图像分组，各自覆盖全部500张。固定阈值0.25，先筛选，再以IoU≥0.5一对一匹配。

背景复杂度取256×256归一化灰度图的中央差分梯度均值，排除外扩4像素的UAV／鸟类框；低中高阈值由1024张训练图的三分位数固定（0.01101115／0.01514436），不随验证误差调整。这是纹理代理指标，不是人工场景分类。低纹理只有16图、高纹理有391图，漏检率并不随该指标单调变化。

153/163次漏检来自d<8像素目标，但这类目标本身占441/486个UAV；d≥16只有5个目标。中纹理组FP密度最高（0.441/图）。

原始标注有234个鸟框、分布于144张图。UAV匹配后把剩余预测再与鸟框以IoU≥0.5一对一匹配，得到20个鸟相关误报，占119个误报的16.81%，即8.55%的标注鸟被报为UAV；其余99个误报未归因。含鸟／不含鸟的FP密度为0.271／0.225，UAV漏检率为20.93%／38.10%，两者样本构成不同。

AP按原验证清单顺序、固定同分排序计算。三次重复中预测完全一致，重复的只是计时。该测试不覆盖功耗、冷启动存储、长时间摄像头稳定性和独立标注视频。
