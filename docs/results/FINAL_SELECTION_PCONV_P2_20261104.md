# 最终选型：PinP2-YOLO

最终部署平台为树莓派5＋HAILO10H。用户根据完整硬件结果确认选择从零100轮的PinP2-YOLO，作为精度、漏检、参数量与速度的综合部署折中；这不是沿用历史精度优先自动排序，也不声称所有单项最优。历史排序及评测数值保持不变。

|---|---:|

相对YOLO11n，组合模型的H10 AP95低1.714个百分点，但管线速度快22.56%、参数少2.85%、漏检率低0.823个百分点。相对YOLOv8n，AP95低0.459个百分点、漏检率高3.086个百分点，但速度快20.52%、参数少16.43%。保留这些取舍，不用后加权总分制造唯一优势。

PConv＋SD在FP32精度较高，但H10 AP95为18.125%、速度7.17FPS、FP331，不将FP32优势直接外推到H10。原YOLO26n虽最快30.06FPS，其H10 AP95仅15.204%。

模型采用30个顶层模块组成的实际网络，第1层PConv，检测输入为第19／22／25／28层，对应P2／P3／P4／P5，步长4／8／16／32。P2高分辨率分支与P3／P4／P5共同参与检测。

原生AP与部署AP保留不同口径；固定阈值conf0.25先筛选再IoU0.5一对一匹配。FPS含前后处理，不含绘图、编码、网络。H10为骨干INT8、指定原始输出层a16_w16混合精度；提供1024张训练图，日志实用统计64张，禁用梯度微调。所有外部结果仅为诊断，不参与阈值或权重选择。

方法命名：**PinP2-YOLO**（Pinwheel-enhanced P2 Fusion YOLO）统一指代该实际YOLO26n浅层PConv与P2融合模型；模型ID、冻结权重、评测数值保持一致。
