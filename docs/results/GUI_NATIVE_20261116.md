# Pi 本机视频GUI优化与显示稳定性（2026-11-16）

本次保持冻结PinP2-YOLO HEF、conf0.25、NMS IoU0.4不变。新增本机内存调用路径：视频缓存到Pi后本机解码，RGB直接传入既有H10引擎，去掉逐帧网络往返和PNG/JPEG编解码；不在Mac推理。检测图每帧只标注一次，目标放大复用标注结果，相同尺寸画面不反复重置视图缩放。

## 显示测量口径

实际运行于Pi现有Wayland/labwc桌面，已连接HDMI显示器，1920×1080、约60Hz；使用系统PyQt5和HailoRT5.1.1，没有创建虚拟显示器或改变系统显示设置。

显示FPS来自检测视图每个不同帧的 `paintEvent` 完成时间，不是推理调用频率、视频文件标称FPS或显示器60Hz。Qt会合并更新请求，因此单纯统计`show_frame`不足以代表绘制完成次数；参见 [Qt QWidget绘制说明](https://doc.qt.io/qt-6/qwidget.html)。本记录测量真实窗口绘制，不直接测量显示器扫描输出或录屏采样率。

## 网络与素材

每帧网络上传量为0。启动器以SHA256校验已有视频缓存，后续演示无需重复上传。同一网络下先前Mac→Pi逐帧PNG请求均值3.30秒、JPEG95请求均值2.19秒；这些是旧网络路径的请求延迟，不是与本次相同绘图/导出配置的严格硬件基准。

47MB长片段首次上传在当前中继网络过慢，本次主动取消未完成上传，保留记录，不把其视为缓存成功。5分钟稳定性验证使用已缓存的真实30帧片段循环；片段由UAV-CB图像按文件名排序构建，不声称原始连续录像或独立视频准确率。后续完整素材宜提前缓存或在Pi本地拷贝。
