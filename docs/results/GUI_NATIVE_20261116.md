# Pi 本机视频GUI优化与显示稳定性（2026-11-16）

本次在PinP2-YOLO HEF、conf0.25、NMS IoU0.4下新增本机调用路径：视频缓存到Pi后本机解码，RGB直接送入H10引擎，取消逐帧网络往返和PNG/JPEG编解码，推理全部在Pi上完成。检测图每帧只标注一次，目标放大复用标注结果，相同尺寸画面不重置视图缩放。

## 显示测量口径

实际运行于Pi现有Wayland/labwc桌面，HDMI显示器1920×1080、约60Hz，使用系统PyQt5和HailoRT5.1.1。

显示FPS来自检测视图每个不同帧的 `paintEvent` 完成时间。Qt会合并更新请求，单统计`show_frame`不能代表绘制完成次数，参见 [Qt QWidget绘制说明](https://doc.qt.io/qt-6/qwidget.html)。因此这里的FPS是应用层绘制速度，不等于显示器扫描输出，也低于推理调用速度。

## 实测

首轮20秒本机窗口测试：320帧完成推理，319帧实际绘制（停止时最后一帧已保存但未显示），16.61 FPS，帧间隔P95为68.43ms、最大81.23ms。Pi无降频（`throttled=0x0`），前30帧的框和分数与此前无损PNG服务路径逐值相同。

5分钟循环测试已通过，运行300.24秒，4942帧完成推理，4941帧实际绘制：

| 指标 | 实测 |
|---|---:|
| 平均实际窗口绘制 | 16.51 FPS |
| 前60秒 / 后60秒绘制 | 16.48 / 16.57 FPS |
| 帧间隔P95 / 最大 | 68.54 / 102.87 ms |
| H10处理 / 本机调用均值 | 53.82 / 57.09 ms |
| 稳定阶段RSS | 344.4–361.4 MiB |
| 第30–60秒 / 最后30秒平均RSS | 358.23 / 358.92 MiB |
| 最高温度 | 60.6 °C |

全程无检测与显示错误、无降频，设备正常释放。Mac 31项GUI测试通过；Pi 31项中30项通过、1项Mac专属测试跳过，详见 [汇总JSON](GUI_NATIVE_20261116.json)。5分钟片段循环的稳定性不等同于长期现场运行；开启录屏后绘制速度会降至约10 FPS（见下方录制记录）。测试后还修正了本机模式的传输标签并隐藏无关的编解码选项，推理路径不变。

## 网络与素材

本机路径每帧网络上传量为0，已有视频缓存可重复使用、无需再上传。对照旧网络路径：Mac→Pi逐帧PNG请求均值3.30秒、JPEG95请求均值2.19秒，远慢于本机路径。

47MB长片段在当前中继网络上传过慢，已提前取消。5分钟稳定性验证使用已缓存的30帧片段循环（UAV-CB图像按文件名排序合成）。完整素材宜提前缓存或直接拷贝到Pi。
