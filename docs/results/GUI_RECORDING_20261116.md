# Pi native GUI recording / 树莓派本机操作录屏

2026年11月16日在树莓派5真实Wayland桌面完成完整GUI操作录制，使用当前PinP2-YOLO HEF和HAILO10H。界面保持英文为主、中文辅助。

完整成片为 **1920×1080、25 FPS、6分52.92秒、无音频**，依次包含图片选择与检测、切换视频、本机实时检测、暂停、恢复及停止。原始录屏由Pi生成并在回传后核验SHA256，播放版在Mac本地重新压缩，保留完整时间顺序，没有剪切、加速或替换画面。原始录屏也保留在本地项目结果包。

本地项目导航新增 `13_GUI操作演示视频`，目录内的 `index.html` 可播放并按章节跳转，`PinP2_H10_GUI_full_demo.mp4` 为推荐成片，`gui_demo_raw.mp4` 为原始录屏。录屏与运行记录保留在本地，不提交公开Git。可核对[汇总JSON](GUI_RECORDING_20261116.json)。
