# Pi native GUI recording / 树莓派本机操作录屏

2026年11月16日在树莓派5真实Wayland桌面完成完整GUI操作录制，使用当前PinP2-YOLO HEF和HAILO10H。界面保持英文为主、中文辅助。

本页记录首版6分53秒录屏；当前演示入口使用后续的[3分46秒英文配音、双语字幕版本](GUI_NARRATED_20261116.md)。两版的显示速率分别记录。

成片为 **1920×1080、25 FPS、6分52.92秒、无音频**，依次包含图片选择与检测、切换视频、本机实时检测、暂停、恢复及停止。原始录屏由Pi生成，播放版在Mac本地重新压缩，保留完整时间顺序，没有剪切、加速或替换画面。

本地项目导航的 `13_GUI操作演示视频` 目录内 `index.html` 可播放并按章节跳转，`PinP2_H10_GUI_full_demo.mp4` 为成片，`gui_demo_raw.mp4` 为原始录屏。运行数据见[汇总JSON](GUI_RECORDING_20261116.json)。
