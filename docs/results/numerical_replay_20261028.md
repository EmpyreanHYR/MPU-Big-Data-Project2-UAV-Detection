# 早期EMA的AMP/FP32数值复查

2026-10-28，在原训练CUDA环境执行无梯度回放，随后执行官方训练验证路径的FP32恢复复验。两次归档全部文件的SHA256与取回确认均通过，结束后实例已确认关机。本机没有训练。机器可读结果见[JSON](numerical_replay_20261028.json)。

B0的周期检查点保存epoch=30、EMA更新834次，对应完成第31轮；B1保存epoch=10、EMA更新384次，对应第11轮。两份均有真实EMA且浮点状态有限，B1层1保留PConv；最终best是明确标记的stripped model对照。

四份模型各自使用505幅固定验证图像、batch8、64批，以完全相同顺序比较精度模式。所有模型参数与BN缓冲的前后摘要一致。

| 检查点 | AMP异常批次/64 | FP32异常批次/64 | 首个捕获的顶层异常 |
|---|---:|---:|---|
| B0早期EMA | 3 | 0 | 第22层C3k2 |
| B1早期EMA | 24 | 0 | 第22层C3k2 |
| B0最终best | 0 | 0 | 无 |

27个异常AMP批次改用FP32计算同一份原始预测的loss，仍出现非有限值；完整FP32前向和loss则全部有限。因此异常已定位到与AMP前向精度相关的路径，单独提升loss精度不足以恢复。第22层是本轮顶层hook的定位范围，尚未逐一追踪其内部算子或全部历史异常轮次，不能把两组共有异常单独归因为PConv。

恢复采用项目范围的验证器适配：真实训练AMP标志保持不变，官方验证器通过只读trainer视图使用FP32预处理、前向和loss，并严格拒绝非有限预测、loss或指标。四份检查点各505图像均通过实际官方训练验证路径，参数与BN状态不变。该复验没有执行训练、反向传播或优化器。
