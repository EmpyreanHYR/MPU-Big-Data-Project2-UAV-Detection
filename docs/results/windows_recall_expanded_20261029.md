# 扩充训练数据后的召回实验

2026-10-29，新的 Windows GPU 微调已实际开始，第1轮完成655/655批，训练和固定505幅验证的数值均有限，第2轮训练批次已观察到。当前仍在训练，尚无最终效果或部署改善结论。原B0与此前微调权重均保留，部署默认未变。机器可读记录见[实验记录](windows_recall_expanded_20261029.json)。

训练输入为2617幅：保留原1438幅，新增1000幅作者训练划分中的红外正样本，以及179幅来自训练图像的背景裁块。200个裁块候选均已目视，21个含不明天空点或属于不明确子组的候选被排除；批准裁块避开已标目标及16像素边界，审核未识别到其他可见UAV，不能据此证明物理上不存在目标。裁块属于派生增强，不能算179张独立原始图像。原505幅验证集不变，开发IR300和两个提前保留的新录制族不参与训练。

新增1000幅图像全解码、标签边界与源文件校验通过，与全部3000幅原图及开发IR300无相同像素。固定的低成本近重复筛查对原3000幅参考得到零候选；这不证明源视频或背景独立，也不把10个录制命名族当作10个独立场景。数据语义与分发来源依据[数据来源](../datasets/SOURCES.md)中记录的作者资源；媒体和原标注保持私有。

本次从完整原B0重新初始化，训练器重建后全部状态与键匹配。配置为AdamW、学习率0.0001、640输入、batch4、FP32训练与验证、关闭mosaic，最多20轮；TF32在本进程显式关闭。验证显式设置`nms=False`并实核one-to-one，训练best按该分支的AP50:95选择，每5轮保留候选。源代码检查、实际运行环境和数据预检通过；独立守护将新任务限制在两小时内，Mac/Pi没有训练。

第1轮验证P/R/AP50/AP50:95为59.40%/40.73%/45.61%/17.18%，参数与BN状态在验证前后不变。这只是早期结果，不能与原92.31%的IR精确率直接比较。原92.31%对应60TP/5FP，召回仅20%；此前微调提高检出同时大幅增加误检，详见[同环境配对](windows_recall_paired_20261028.md)。

训练结束后，将在相同Windows运行环境、输入、one-to-one分支和精度控制下比较原B0与保存候选，仅用固定505验证选择检查点与工作点：在精确率不低于同路径B0固定工作点减2个百分点的条件下最大化召回；随后再解释开发IR300和保留录制族表现。数据、学习率、选模分支及TF32控制同时变化，本次不能作为仅扩充数据的匹配消融，也不承诺增加图像一定改善效果。
