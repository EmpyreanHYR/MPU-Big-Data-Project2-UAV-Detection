# 扩充数据后的召回实验：序列检出改善，原验证集退化

2026-10-29，扩充训练已正常完成20个完整轮次，并完成同环境检查点配对。**新模型在已有红外开发序列上明显改善，但原505幅验证集退化，未通过预先固定的选点约束，部署继续使用原B0。** 训练权重和24个记录文件、配对预测和25个记录文件均已完整取回，全部SHA、逐帧计分与远端确认通过。[机器可读记录](windows_recall_expanded_20261029.json)保留完整结果。

同Windows、FP32、关闭TF32、640输入、显式one-to-one、无额外NMS，在固定conf=0.25、匹配IoU=0.5时：

| 评价数据 | 模型 | TP / FP / FN | 精确率P | 召回率R |
|---|---|---:|---:|---:|
| 原505验证图 | 原B0 | 227 / 75 / 264 | 75.17% | 46.23% |
| 原505验证图 | 扩充best | 179 / 75 / 312 | 70.47% | 36.46% |
| IR300开发帧 | 原B0 | 60 / 5 / 240 | 92.31% | 20.00% |
| IR300开发帧 | 扩充best | 187 / 14 / 113 | 93.03% | 62.33% |

IR新增检出130帧、丢失3帧，净增127帧；FP由5增至14，精确率仍略升。全8400候选中没有IoU达标框的帧由28降至4，低分定位候选漏检由212降至109。这些是该开发序列的观察，不是全部漏检根因或跨场景收益证明。原92.31%一直是精确率60/(60+5)，原召回只有20%，不能叫总体准确率。IR为已反复观察的相关单序列，全部帧含目标，不能推算背景场景误报小时数或独立test表现。

模型与工作点选择只使用固定505：比较原B0、best、last和实际保存的第1/6/11/16轮，文件SHA去重；所有候选均评估固定阈值0.25/0.10/0.05/0.01。在P不低于同路径原B0@0.25减2个百分点（73.1656%）的条件下最大化R，结果仍为原B0@0.25。全部新增候选均未过此精确率约束。**先写入选择结果，再打开IR图像和标注**；扩充best在IR上的比较属于提前规定的描述性分析，未据此换模型或调阈值。

扩充best的官方指标准确复现训练结束复验；其状态与第1轮周期检查点相同。表中均为保存后重载的配对指标，训练内逐轮EMA与保存重载后的数值存在小幅差异，保留两类记录。训练loss整体下降，原验证集没有同步改善，继续加轮的依据不足。结果提示需要检查场景覆盖与原场景性能的取舍，但当前试验不能单独确定数据量不足、数据混合或其他训练设置是哪一项主因。

训练输入2617幅：原1438幅、1000幅作者train中的红外正样本、179幅训练图像背景裁块。200个裁块候选均已目视，21个含不明天空点或不明确子组的候选被排除；批准裁块避开已标目标及16像素边界，审核未识别到其他可见UAV，不能证明物理无目标。裁块是派生增强，不能算179张独立源图。505验证图不变，IR300和两个提前保留的新录制族不训练；保留族尚未取图或评价。

1000新增图全部解码、源文件和标签边界核验；与全部3000原图及IR300无相同像素，固定低成本近重复筛查对原3000参考得到零候选。文件名录制族不证明真实视频/背景独立，不能称10个独立场景。作者IR/UAV语义、分发与使用边界见[数据来源](../datasets/SOURCES.md)，媒体和标注保持私有。

从完整原B0初始化，训练器重建后所有状态与键一致；AdamW/学习率0.0001、640/batch4/workers0、FP32训练和验证、关闭mosaic与TF32，显式nms=False并实核one-to-one。20轮各655/655批、全部CSV有限；每轮505样本、参数与BN在评价前后不变。训练best按one-to-one AP50:95选择。固定库的save_period=5按从0开始的轮号取模，实际保存完成第1/6/11/16轮及完整last20；此前称5/10/15/20不准确，已按真实文件比较，未补造权重。
