对已完整SHA核验的两分支配对预测做后续分析，没有重新执行模型或训练。固定505张验证图、640输入、置信度0.25、UAV匹配IoU0.5；先按原来的降序IoU贪心匹配确定误检，再统计其中与已标注鸟框IoU≥0.5的数量。505张中有491个UAV框、227个鸟框。原始[配对结果](windows_recall_paired_20261028.md)及默认部署设置保持。

“未分类”不等于已经识别为云、树或建筑，也不能凭缺少鸟框重叠就认定标注错误。这次没有对IR视频中的误检作类别归因，不能把验证集发现直接推广到IR。验证图像均在一个推断背景视图组中，不代表已知的同一原始视频；分析仍属于开发，没有独立测试成绩或优化成功结论。

坐标核验：保存的验证GT和预测都在544×672批次画布中；原640×512鸟框按相同流程加16像素XY边缘。全部保存UAV GT与转换后的原标注一致，回到原图坐标重新计算也得到完全相同计数。该处理只用于本次归因，没有修改历史预测、标注或评分。核查由同一主代理完成，无第二审查者。
